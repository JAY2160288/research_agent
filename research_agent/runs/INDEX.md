# runs/ 색인 — 수행 입출력 결과

입력은 "주제" 열의 한 줄, 출력은 각 행의 `report.md`(한국어 주제는 한국어본, 영어 원문은 같은 폴더 `report.en.md`) 이다. 같은 폴더의 `brief.json`(구조화 출력), `events.jsonl`(단계 전이·LLM/도구 호출 로그), `cost.json`(비용·결정적 지표), 노드별 중간 산출물(`topic_frame.json`·`plan.json`·`evidence.json`·`critique_N.json`·`replan_N.json`)도 함께 있다.

- mode: `graph` = 최종 구조(역할 분리 + Critic/Replan), `baseline` = 단일 ReAct (비교 기준점)
- 비고: `클린룸` = 새 clone + 키 1개 + README 명령 3개로 돌린 재현 실행 · `ablation Tn·X` = 주제 Tn 의 조건 X (A 베이스라인 / B Critic 없음 / C 결정적 Critic / D 결정적+LLM Critic = 최종) · `judge`/`support` = 사후 LLM 채점·주장-근거 지지 검증 결과 포함 · `한국어본` = report.md 가 한국어
- 지표 열(인용 검증 / claim 출처 / sub-RQ 커버 / Gap 근거)은 `cost.json` 의 `checks` 를 그대로 옮긴 것이다. 이 표는 `scripts/summarize_runs.py --md` 와 같은 원천에서 만들었다.
